# منشئ الشرائح

يجمع المنشئ **الشروط** في مجموعات «و» / «أو» لتحديد جمهور دقيق. يربط كل شرط بين حقل ومعامل وقيمة. يُستخدم لإنشاء [شريحة](help:segments) أو تعديلها.

## فئات الشروط

| الفئة | أمثلة |
| --- | --- |
| سمات جهة الاتصال | الولاية = الجزائر، SOCIETE يحتوي «Meuble» |
| القوائم | ينتمي إلى القائمة X، لا ينتمي إلى القائمة Y |
| التفاعل مع البريد | فتح، نقر، لم يفتح خلال آخر N يومًا |
| التواريخ | أُنشئ بعد…، آخر استيراد قبل… |
| PagesJaunes | فئة أو منطقة ناتجة عن [بحث PagesJaunes](help:pagejaunes-search) |

## خطوة بخطوة

1. انقروا على **إضافة شرط** واختاروا الفئة.
2. حددوا الحقل والمعامل والقيمة.
3. اجمعوا الشروط في مجموعات وبدّلوا بين **و / أو**: مع «و» يجب تحقق الكل، ومع «أو» يكفي شرط واحد.
4. انقروا على زر الحساب لرؤية عدد جهات الاتصال المطابقة مباشرة.
5. سمّوا الشريحة واختاروا مجلدًا وانقروا على **حفظ**.

## نصائح

- ابدأوا بشرط واسع ثم دقّقوا مع مراقبة العدد.
- تعتمد شروط التفاعل على الإرسالات السابقة: شريحة «فتح» تبقى فارغة ما دامت لم تنطلق أي [حملة](help:campaigns).
- يشير مؤشر إلى التعديلات غير المحفوظة؛ احفظوا قبل المغادرة.
- الشريحة الموروثة من قائمة قديمة تحمل شارة وقد تكون للقراءة فقط.

بعد الحفظ، ينشئ **استخدام في حملة** الإرسال المستهدف مباشرة.
