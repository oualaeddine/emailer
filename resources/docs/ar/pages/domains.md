# النطاقات

تعرض صفحة **النطاقات** نطاقات الإرسال لديكم وحالة سجلات DNS الخاصة بها: **DKIM** و**SPF** و**DMARC**. يثبت النطاق الموثّق لخدمات البريد أن رسائلكم شرعية ويحمي سمعتكم كمرسل.

## دور السجلات الثلاثة

| السجل | الدور |
| --- | --- |
| SPF | يسرد الخوادم المسموح لها بالإرسال باسم نطاقكم |
| DKIM | يوقّع كل رسالة لضمان عدم تغييرها |
| DMARC | يحدد ما يُفعل بالرسائل التي تفشل في الفحوص |

## توثيق نطاق

1. انقروا على **إضافة نطاق** واكتبوه، مثل `monentreprise.dz`.
2. يولّد التطبيق السجلات المطلوب نشرها.
3. انسخوا قيم DKIM وSPF وDMARC إلى منطقة DNS لدى مزوّد الاستضافة أو المسجّل.
4. عودوا وانقروا على **تحقق**: يعرض كل سجل حالته.

قد يستغرق انتشار DNS من دقائق إلى ساعات؛ إذا فشل التحقق فانتظروا ثم أعيدوا المحاولة.

## ربط المرسلين

بعد توثيق النطاق يُعتمد [المرسلون](help:senders) الذين يستخدمونه تلقائيًا.

## نصائح

- لا تحذفوا سجل SPF موجودًا: ادمجوا القيم الجديدة مع القديمة.
- ابدأوا DMARC بسياسة مرنة ثم شدّدوها بعد استقرار الإرسال.
- النطاق غير الموثّق سبب شائع للرفض الظاهر في [سجلات المعاملات](help:transactional-logs).
