# Listes

Une **liste** est un regroupement statique de contacts que vous ciblez dans vos campagnes. La page **Listes** affiche, dossier par dossier, le nom, le nombre de contacts, la date de création et le dernier import de chaque liste.

## Créer une liste

1. Cliquez sur **Créer une liste**.
2. Saisissez un nom clair, par exemple « Menuisiers Béjaïa 2026 ».
3. Choisissez un dossier pour la ranger, puis validez.

## Alimenter une liste

- Ouvrez la liste puis cliquez sur **Importer dans cette liste** : l'[assistant d'import](help:recipients-import) démarre avec la liste déjà sélectionnée.
- Ou, depuis le tableau [Contacts](help:recipients), cochez des lignes et utilisez **Ajouter à une liste**.

## Organiser avec les dossiers

L'arborescence à gauche permet de filtrer par dossier ; **Toutes les listes** affiche l'ensemble. Les dossiers n'ont aucun effet sur l'envoi : ils servent uniquement à vous repérer.

## Utiliser une liste dans une campagne

À l'étape **Destinataires** d'une [campagne](help:campaign-setup), cochez les listes à cibler et, au besoin, celles à exclure. Les contacts présents dans la [liste de suppression](help:suppression) sont toujours écartés.

## Conseils

- Une liste est **statique** : pour une audience qui se met à jour toute seule selon des conditions, créez plutôt un [segment](help:segments).
- Supprimer une liste ne supprime jamais les contacts qu'elle contient.
- Un même contact peut appartenir à plusieurs listes ; il ne reçoit alors qu'un seul exemplaire d'une campagne qui les cible toutes.

Voir aussi : [Détail d'une liste](help:list-detail).
