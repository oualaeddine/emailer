# Pages de désinscription

Cette page personnalise **ce que voit un contact qui se désinscrit** : textes, logo et couleurs issus de votre [identité visuelle](help:settings-branding), message de confirmation et, en option, une page de préférences (de la forme `/preferences/…`) qui permet de se retirer liste par liste plutôt que de tout quitter.

## Créer ou modifier une page

1. Cliquez sur **Créer une page** (ou ouvrez une page existante).
2. Adaptez le titre, le message et le bouton de confirmation.
3. Activez les **préférences** si vous voulez laisser le contact choisir les [listes](help:lists) dont il se désabonne.
4. Ouvrez l'**aperçu** pour contrôler le rendu.
5. Enregistrez.

## Utiliser la page dans une campagne

Dans les paramètres supplémentaires d'une [campagne](help:campaign-setup), choisissez la page voulue. Le lien de désinscription inséré dans l'e-mail y mènera.

## Ce qui se passe à la désinscription

Le contact est ajouté à la [liste de suppression](help:suppression) et n'est plus ciblé par vos envois. Avec les préférences, seule la liste choisie est quittée.

## Conseils

- Gardez un ton aimable et sans culpabilisation : un départ propre protège votre réputation.
- La désinscription doit rester simple, en un clic ; ne demandez pas de connexion.
- Proposer les préférences réduit nettement le nombre de départs complets.
- Pour permettre la correction des données plutôt que le départ, voir les [formulaires de mise à jour](help:update-profile-forms).
