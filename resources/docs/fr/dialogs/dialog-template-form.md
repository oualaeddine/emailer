# Créer un modèle

La fenêtre **Créer un modèle** sert à ajouter une nouvelle mise en page à votre bibliothèque. Elle s'ouvre depuis le bouton **Nouveau modèle** de la page [Modèles](help:templates). Trois éléments seulement sont à fournir : un nom, une catégorie facultative et le contenu du message.

![Fenêtre de création d'un modèle](/docs/screenshots/templates/02-dialog.png)

## Les champs

| Champ | Obligatoire | Rôle | Exemple |
| --- | --- | --- | --- |
| **Nom** | Oui | Identifie le modèle dans la bibliothèque | `Offre commerciale — menuiserie` |
| **Catégorie** | Non | Regroupe les modèles similaires ; texte libre | `Prospection` |
| Zone de rédaction | Recommandé | Le contenu réutilisable du message | Voir ci-dessous |

Le bouton **Enregistrer** reste inactif tant que le champ **Nom** est vide. **Annuler** ferme la fenêtre sans rien créer.

## Bien nommer un modèle

Le nom est ce que vous lirez dans la liste dans six mois. Un nom qui décrit l'usage vaut mieux qu'un nom qui décrit le design :

- Utile : `Relance devis — 15 jours`, `Vœux fin d'année — clients Oran`
- Peu utile : `Modèle 2`, `Test bleu`

Pour la catégorie, tenez-vous à un petit vocabulaire stable dans toute l'équipe — par exemple `Prospection`, `Relance`, `Information`, `Administratif`. Une catégorie mal orthographiée crée un groupe séparé.

## Rédiger le contenu

La zone de rédaction est le même éditeur que celui du [rédacteur d'e-mail](help:composer). Sa barre d'outils propose **Gras**, **Italique**, **Souligné**, **Liste à puces**, **Liste numérotée** et **Insérer un lien**. Pour un lien, sélectionnez le texte, cliquez sur l'icône de lien, puis saisissez l'adresse demandée (par exemple `https://menuiserie-bejaia.dz/catalogue`).

Conseil : laissez volontairement des zones à personnaliser, bien visibles, que le rédacteur remplacera à chaque envoi.

```
Bonjour,

Menuiserie Bejaia vous propose sa nouvelle gamme de portes coupe-feu.

- Livraison sous 15 jours sur Béjaïa, Sétif et Alger
- Garantie 5 ans
- [PRÉCISER L'OFFRE DU MOIS]

Cordialement,
```

Un modèle court et sobre passe mieux les filtres anti-spam qu'une page couverte d'images.

## Enregistrer

**Enregistrer** crée le modèle : la fenêtre se ferme et la nouvelle carte apparaît immédiatement dans la bibliothèque. Les champs sont remis à zéro, prêts pour un modèle suivant.

## En cas de problème

- **Le bouton Enregistrer est grisé** : le champ **Nom** est vide, ou l'enregistrement est déjà en cours. Un seul clic suffit.
- **La mise en forme collée depuis Word est étrange** : Word ajoute du code invisible. Retapez le passage dans l'éditeur plutôt que de le coller.
- **Vous avez fermé la fenêtre par erreur** : rien n'est conservé tant que vous n'avez pas cliqué sur **Enregistrer**. Il faut recommencer.
- **Vous vouliez modifier un modèle existant** : cette fenêtre ne fait que créer. Pour retirer un ancien modèle de la circulation, utilisez **Archiver** depuis la page [Modèles](help:templates).
